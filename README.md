# Guide de lecture critique d’articles

Guide interactif (hors-ligne, sans dépendance) pour lire des articles scientifiques lors d’une revue de littérature : trois passes, lecture section par section, grilles selon le design, fiche de notes exportable.

Les cases cochées, le design choisi et les fiches sont enregistrés localement (localStorage).

## Utilisation
Ouvrir `index.html`, ou déployer sur GitHub Pages (Settings → Pages → branche `main`, dossier `/ (root)`).

## Structure (version à plat)
- `content.js` : tout le contenu (modifiable sans toucher au code)
- `store.js` (stockage), `render.js` (composants), `app.js` (navigation)
- `style.css`
